01CONTEXT

Fourteen months at ITSAP – Institut de l’abeille (INRAE), in Avignon, first as an intern then on a fixed-term contract, leading the technical side of Miellée — an internal tool for the team’s connected beehive scales.

02PROBLEM

Weight data from connected beehive scales has to be cleaned and standardised before it means anything: missing points, inconsistent time steps, values to correct before a weight curve is readable.

03SOLUTION

An R pipeline that cleans the data, corrects the weight curves, and fits a segmented regression to find where each nectar flow begins and ends.

Each year’s data is validated and corrected, then a piecewise linear model — with automatic breakpoint detection — locates the segments of fastest weight gain: the “miellées”. Results are stored in a shared PostgreSQL model and explored through a Shiny dashboard.

04REPORTING

Geolocated indicators, and a report at the end of the pipeline.

Weight-gain indicators are placed on a map, and the same data feeds automated reports — built with R Markdown and LaTeX (Beamer) — for the team and its partners.

05MY ROLE

The technical side, alone: the cleaning algorithm, the database model, the Shiny interface and its Dockerized deployment.

06STACK

R/Shiny/PostgreSQL/Plotly/Docker/R Markdown/LaTeX (Beamer)
