Data × Code × Product

My approach

Four things that stay true across seven very different projects — from a confidential research mission to a company I’m co-founding.

01END TO END, ALONE

Founder, sole developer, or the person doing “everything technical” as co-founder — on every project here, I go from the data to the interface myself, without handing off.

02A REAL PRODUCT, NOT JUST AN ANALYSIS

SenBioStat doesn’t stop at a statistical test — it writes a PDF report. Miellée isn’t a notebook — it’s a dashboard someone actually uses. That’s the whole point of Data × Code × Product.

03TESTED BEFORE IT SHIPS

693 tests on DocuSen, 300+ on YoonuJob, 102 on Sentazur. Not a box to tick afterward — part of what “done” means.
